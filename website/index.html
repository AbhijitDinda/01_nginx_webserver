What This Project Demonstrates

🐋

Docker Containerization

Nginx running inside an Alpine Linux Docker container. 23MB image, fast pull, consistent environment.

☁️

AWS EC2 Deployment

Hosted on AWS EC2 t2.micro inside a custom VPC with security groups and proper IAM configuration.

⚙️

GitHub Actions CI/CD

Automated pipeline: push code → build image → push to Docker Hub → deploy to EC2. Zero manual steps.

📦

Static File Serving

Serves HTML, CSS, JS, PNG, JPEG, and PDF files with proper MIME types and cache headers.
