🎓 Understanding 5xx Errors
Code Name Meaning
500 Internal Server Error Generic server error. Check Nginx error logs.
502 Bad Gateway Nginx received invalid response from upstream server.
503 Service Unavailable Server temporarily unable to handle requests. Maintenance mode.
504 Gateway Timeout Nginx didn't receive response from upstream in time.

In our static Nginx setup, 5xx errors typically mean Nginx itself crashed or had a configuration issue. Check: docker logs nginx-webserver on EC2.
