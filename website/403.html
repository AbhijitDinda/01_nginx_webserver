🎓 What is HTTP 403?

HTTP 403 Forbidden is a standard HTTP response status code indicating that the server understands the request but refuses to authorize it. Unlike 401, the client's identity is known but they lack access rights.

Common causes: File system permissions on the server, autoindex is disabled and there is no default index.html file, IP restrictions/firewall blocks, or lacking required API roles.

HTTP/1.1 403 Forbidden
Server: nginx
Content-Type: text/html
